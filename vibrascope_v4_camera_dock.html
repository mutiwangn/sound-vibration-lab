启用摄像头和麦克风

点击后浏览器会请求授权。摄像头用于追踪红色标记点，麦克风用于同步记录相对分贝变化。

✓ 摄像头：追踪钢尺端点、鼓面纸片或音叉叉齿端部
✓ 麦克风：记录分贝随时间的变化

建议使用 GitHub Pages 的 HTTPS 地址。授权失败时，请在浏览器设置中允许相机与麦克风。
